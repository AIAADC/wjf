# ➗ 微积分课件

本仓为 AIAADC 大一课程资料仓，主要整理微积分课堂课件、习题课资料与补充笔记。  
年级总入口见：[AIA 大一课程资源总仓](https://github.com/AIAADC/Resources-for-freshman-in-AIA)

</div>

---

## 资料内容

- 课堂课件：极限、连续、导数、积分等专题资料
- 习题课资料：章节练习、专题讲解和补充材料
- 模拟考试：`2025微积分模拟考试` 目录
- 手写笔记：右侧 Release 中有学长/学姐整理的手写笔记压缩包

## 使用建议

1. 平时学习优先按课堂进度查看课件。
2. 考前复习可结合年级总仓中的真题、答案和专题复习。
3. 手写笔记适合作为查漏补缺材料，不建议完全替代课本和习题。
